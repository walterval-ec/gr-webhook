# GR Asesoría Contable — Webhook WhatsApp

Webhook que recibe mensajes entrantes al número de Cloud API
y los reenvía al número personal de Laura con nombre y número del cliente.

## Variables de entorno requeridas en Railway:
- META_ACCESS_TOKEN
- META_PHONE_NUMBER_ID
- WEBHOOK_VERIFY_TOKEN
- NUMERO_REENVIO
- META_API_VERSION
